# Currículum Vitae — José Federico Castro Tramontina

Proyecto HTML/CSS preparado para:

- visualización en navegador
- lectura por sistemas ATS;
- exportación a PDF en una página A4;
- posterior traducción al inglés.

## Estructura

```text
resume/
├── index.html
├── css/
│   ├── style.css
│   └── print.css
└── thumbnails/
    ├── email.svg
    ├── github.svg
    ├── linkedin.svg
    ├── location.svg
    └── whatsapp.svg
```

## Uso

Abrir `index.html` en Firefox, Chromium o Google Chrome.

Para exportar:

1. Abrir la opción **Imprimir**.
2. Elegir **Guardar como PDF**.
3. Papel: **A4**.
4. Escala: **100 %**.
5. Márgenes: **ninguno**.
6. Activar **gráficos de fondo**.
7. Desactivar encabezados y pies de página del navegador.

## Observación

Los datos de contacto aparecen como texto visible además de estar enlazados. Esto mejora la accesibilidad, la lectura por ATS y la utilidad del PDF impreso.
